# Premier pass

Quero criar um site de venda de ingressos para eventos no estilo sympla e ingresse.com.

quero ter a visao geral sem login, a visao do usuario que se cadastra compra e tem seus ingressos, e a visao de quem administra os eventos.

quero ter a opção de compra direto pelo site integrada com um gateway de pagamento.

quero um site profissional e moderno, com layout bonito e interativo.

vou precisar aplicar backend, banco de dados e segurança
